## 🧠 Overview

Wallpaper Engine is a Windows desktop application designed for animated and interactive wallpapers. It supports 2D and 3D scenes, videos, websites, and interactive backgrounds, while also providing an editor for creating custom wallpaper projects. Wallpapers can be used across multiple monitors and configured to pause when another application or a fullscreen game is active. :contentReference[oaicite:0]{index=0}

## 🚀 Key Features

| Feature | Description |
|---|---|
| 🌌 Live Wallpapers | Use animated backgrounds instead of static desktop images |
| 🎮 Interactive Scenes | Wallpapers can respond to mouse input and other interactions |
| 🎥 Video Wallpapers | Use supported video files as desktop backgrounds |
| 🧊 2D & 3D Graphics | Choose from animated 2D scenes and 3D environments |
| 🌐 Web Wallpapers | Display supported websites and web-based scenes |
| 🖥️ Multi-Monitor | Configure wallpapers for multiple displays |
| 🎨 Wallpaper Editor | Create and customize your own animated wallpapers |
| ⚡ Performance Controls | Automatically pause or stop wallpapers during demanding tasks |
| 🎵 Dynamic Effects | Create audio-reactive and other dynamic visual effects |
| 🛠️ Workshop Support | Browse and manage a large collection of community-created wallpapers |

## Additional Information for Windows Users

Wallpaper Engine provides several options for balancing visual quality and system performance. Wallpapers can automatically pause when another application is active or when a game is running in fullscreen or borderless mode.

The editor supports creating scenes from images, videos, websites, 2D elements, and 3D content. Recent updates have also introduced dynamic model generation, improved text rendering, additional visual effects, and HDR video support. :contentReference[oaicite:2]{index=2}

For multi-monitor setups, the application supports common aspect ratios and native display resolutions, making it possible to configure different animated backgrounds across connected screens. :contentReference[oaicite:3]{index=3}
